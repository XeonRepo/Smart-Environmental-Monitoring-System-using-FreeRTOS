# Smart-Environmental-Monitoring-System-using-FreeRTOS
STM32/ESP32 | FreeRTOS | Embedded C | UART | I2C | ADC

Developed a multitasking embedded application using FreeRTOS, implementing separate tasks for sensor acquisition, LCD display,
and serial communication.

Used task scheduling, queues, and semaphores to enable efficient inter-task communication and synchronization.

Interfaced temperature and humidity sensors using I2C, and displayed real-time sensor data on an LCD/UART terminal.

Optimized task priorities and execution timing to achieve responsive and reliable real-time performance.
